# Fatiha — version « Ciel » (4I•MINE), non publiée

Base : copie de `fatiha/index.html` en ligne (dépôt Miracle-, 150 950 octets, conservée telle quelle dans `source-fatiha-en-ligne.html`).
`index.html` = cette copie + 2 lignes (`assets/ciel.css`, `assets/ciel.js`). Le texte d’hommage et le script d’origine ne sont pas modifiés.

Ajouts (bouton « Ciel ») : voyage artistique à travers les planètes avec interlude trou noir (mention « échelles non physiques »),
avions OpenSky (Europe), satellites CelesTrak OMM JSON + SGP4 via satellite.js (couleurs LEO/MEO/GEO/HEO, temps ×1/×60/×600),
carte Leaflet/OSM des zones de recherche de webcams, ambiance sonore Web Audio, journal local des échecs (localStorage).
Repris de l’original : globe Cesium, lieux, iptv-org + HLS, Radio Browser, GDELT, export 5K, repli statique.

Ouvrir en local : `cd /workspace/partage/fatiha-veille-4imine && python3 -m http.server 8765` puis http://localhost:8765/
